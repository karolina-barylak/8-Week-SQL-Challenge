# 8 Week SQL Challenge

Repozytorium przedstawia rozwiązanie 8 studium przypadków z wyzwania [8 Week SQL Challenge](https://8weeksqlchallenge.com/) przygotowane przez [Danny With Data](https://www.datawithdanny.com/).

Zawiera moje rozwiązania oraz analizy. Rozwiązuje praktyczne problemy za pomocą SQL oraz logicznego myślenia analitycznego.</br>
Projekt skupia się na rozwiązywaniu realnych problemów biznesowych z użyciem SQL, w tym:

- czyszczenie danych,
- łączenie tabel (JOIN),
- agregacja i analiza danych,
- analiza klientów,
- metryki sprzedażowe,
- funkcje rankingowe,
- oraz bardziej zaawansowane zapytania SQL.
